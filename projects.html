Exception Guardian

Team wh0-Kn0w5 · built with Narasimha Tiruveedula

An open-source Python CLI and Claude Code playbook that re-checks Tenable risk exceptions that were accepted once and never revisited. It re-grades each one as REVOKE, REVIEW, or OK against CISA KEV, EPSS, asset exposure, and attack paths, then writes tested detections and a threat-hunt brief for the ones to revoke.

  • 324exceptions re-graded on a live lab (7 revoke, 316 review, 1 OK)
  • 25tested detection rules
  • 0breaches in 21 red-team attacks

What it produces

Sigma detections, threat-hunt briefs, and SIEM queries for Splunk, Microsoft Sentinel, and Defender XDR.

Security design

  • Deterministic code, not the LLM, makes every decision
  • Read-only by default, with per-rule confirmation before any change
  • Disables instead of deletes
  • Hooks block risky actions and access to secrets

Red team

21 attacks against the tool: 7 direct and 14 prompt injections hidden in the data. None succeeded.
